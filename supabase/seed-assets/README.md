# Seed assets

`demo-licence.png` is an AI-generated, fictional licence-photo placeholder for the demo seed. It is visibly marked “DEMO ONLY — NOT A VALID LICENCE”, contains no government emblem or real licence data, and is uploaded to the private `licences` bucket at `demo/demo-licence.png`.

Do not replace it with a real person's document or use it as evidence of a pharmacy licence.
